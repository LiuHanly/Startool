1. SDK Architecture Overview

1.1 Library Composition (app/libs/)

Library File Purpose Target Devices
glorystar-hardware-sdk.aar Core hardware abstraction layer (GPIO, UART, sensors, buttons) NEB101, NEB156/215, VegaX

3.1 Barcode Scanning (glorystar-hardware-sdk.aar)

Class: com.glorystar.hardware.BarcodeUtil

Method Signature Description Return Value
Constructor BarcodeUtil(Context context) Initialize with Application context BarcodeUtil instance
setCOM void setCOM(String portPath) Configure serial port path void
init int init() Initialize hardware interface 1 = success
-1 = failure
start void start() Start scanning service void
stop void stop() Stop service & release resources void
getData void getData(OnGetDataListener listener) Register scan data callback void
setScanningMode void setScanningMode(boolean keyboardMode) true = keyboard emulation
false = serial mode		 void
setLightMode void setLightMode(int mode) 0 = ON
1 = AUTO
2 = OFF		 void
setAutoEnter void setAutoEnter(boolean enabled) Append ENTER key after scan void
setBeep void setBeep(boolean enabled) Enable/disable scan beep void

Listener Interface

public interface OnGetDataListener {
  void onDataReceive(String data); // Returns null on error
}

COM Port Mapping

Scanner Model Device Compatibility COM Port
Honeywell N4680 All models /dev/ttyACM2
Newland EM3396 All models /dev/ttyACM0
Critical Note: Always call stop() in Activity.onDestroy() to prevent resource leaks. Hardware initialization failures (init() != 1) typically indicate incorrect COM port assignment or missing root permissions.

Implementation Example

val barcode = BarcodeUtil(applicationContext)

// Set COM port based on scanner type
barcode.setCOM(if (isHoneywell) "/dev/ttyACM2" else "/dev/ttyACM0")

// Initialize hardware (returns 1 on success)
val ret = barcode.init()
if (ret != 1) {
  Toast.makeText(this, "Scanner initialization failed", Toast.LENGTH_SHORT).show()
  return
}

// Start scanning service
barcode.start()

// Register data listener
barcode.getData(object : BarcodeUtil.OnGetDataListener {
  override fun onDataReceive(data: String?) {
    runOnUiThread {
      scanResultTextView.text = data
    }
  }
})

// Configure settings
barcode.setScanningMode(true) // true = keyboard emulation
barcode.setLightMode(1) // 0=ON, 1=AUTO, 2=OFF
barcode.setBeep(true) // Enable beep sound
barcode.setAutoEnter(true) // Append ENTER after scan

// Cleanup in onDestroy()
override fun onDestroy() {
  super.onDestroy()
  barcode.stop()
}

5. Integration Best Practices

5.1 Hardware Lifecycle Management

class HardwareActivity : AppCompatActivity() {
  private var barcode: BarcodeUtil? = null

  override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)
    barcode = BarcodeUtil(applicationContext)

    // Critical: Verify initialization success BEFORE using hardware
    if (barcode!!.init() != 1) {
      showErrorDialog("Barcode scanner not detected")
      return
    }

    barcode!!.start()
    barcode!!.getData { data -> handleScan(data) }
  }

  override fun onDestroy() {
    super.onDestroy()
    // CRITICAL: Always release hardware resources
    barcode?.stop()
    barcode = null
  }
}

5.2 Root Permission Verification

fun hasRootAccess(): Boolean {
  return try {
    val process = Runtime.getRuntime().exec("su -c 'echo test'")
    val reader = BufferedReader(InputStreamReader(process.inputStream))
    reader.readLine() != null
  } catch (e: Exception) {
    false
  }
}

5.3 COM Port Detection Strategy

fun getRfidPort(): String = when (Build.MODEL) {
  "rk3399" -> "/dev/ttyUSB1"   // VegaX (older)
  "rk3568" -> "/dev/ttyS7"     // VegaX (newer) / NEB101
  else -> "/dev/ttyUSB1"      // Fallback
}
